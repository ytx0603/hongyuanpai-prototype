**为什么需要**：jgs123 西晋青瓷唾壶是53件中年代最早的文物，需要确认其胎釉特征以制定修复约束

```

```
**期望拿到**：西晋越窑青瓷的烧成温度、胎釉化学组成、气孔率数据

### A2 明代硬木家具工艺

### A3 康熙青花 vs 光绪青花区别
**为什么需要**：jgs115(康熙青花香炉) 和 jgs113(光绪青花笔筒) 的修复方案不可混淆——两朝青花钴料配方不同  
**搜索提示词**：
```

```
**期望拿到**：康熙浙料(CoO+MnO)与光绪洋蓝(CoO+Fe2O3)的具体化学成分差异

### A4 清代描金漆器工艺
**为什么需要**：jgs93(描金挂屏)和jgs117(描金神祖牌)涉及金层修复——需确认金箔标准  
**搜索提示词**：
```

```
**期望拿到**：文物修复用金箔的纯度标准(是否>=98%Au)、厚度标准(是否0.1-0.15um)

### A5 革命文物特征与保护
**为什么需要**：28件革命文物(1927-1937)的修复有特殊规定——标语/使用痕迹不得清除  
**搜索提示词**：
```

```
**期望拿到**：革命文物修复中保留历史痕迹的权威规定或案例

### A6 郭沫若1965年井冈山题词
**为什么需要**：jgs102-106卷轴涉及领导人题词——确认题词背景和纸质文物保存方法  
**搜索提示词**：
